# Maryame El Khalfi — Portfolio

Engineering portfolio showcasing AI systems, data pipelines, multi-agent analytics platforms, and full-stack software development.

## Tech Stack

- **Framework**: TanStack Start / React 19 / TypeScript
- **Styling**: Tailwind CSS v4 / Ink & Signal Design System (OKLCH)
- **State & Routing**: TanStack Router & TanStack Query
- **Icons & Motion**: Lucide React / Framer Motion

## Local Development

```sh
npm install
npm run dev
```

## Build & Preview

```sh
npm run build
npm run preview
```
